
# Day 5 - Understanding Your Data: Descriptive Statistics 📊

## 📌 Overview
In this lesson, I learned how to understand a dataset using descriptive statistics and explore its basic characteristics before applying Machine Learning algorithms.

## 📚 Topics Covered
- Understanding a dataset
- Exploring rows and columns
- Checking dataset shape and data types
- Using Pandas `info()` and `describe()`
- Calculating mean, median, and standard deviation
- Understanding minimum and maximum values
- Identifying missing values
- Exploring unique values and data distributions

## 🛠️ Tools & Technologies
- Python
- Pandas
- NumPy
- Jupyter Notebook

## 💻 Practical Implementation
This folder contains my practice code and notebook for exploring datasets and calculating descriptive statistics using Pandas.

## 🎯 Learning Outcomes
- Understand the structure of a dataset.
- Summarize numerical features using descriptive statistics.
- Identify potential data quality issues.
- Prepare for Exploratory Data Analysis (EDA).
